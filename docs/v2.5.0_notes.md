# Tinque v2.5.0 — 決定事項と実装メモ

元の原案: `MusicBeatSP-main_11_8/docs/plan_v2.5.0.md`（古いコピーを見て書いたもの。方針はこちらが最新）

## 決定事項
| 項目 | 決定 |
|---|---|
| 新タブ名 | ホーム（`MainNavigationTab.HOME(7)`） |
| 最近端末に追加 | ホームの「新着」 |
| ★と＋の関係 | ★を付けた曲は自動でライブラリの曲にも入る（★を外してもライブラリには残る） |
| メーターに★/プレイリスト追加を混ぜるか | 混ぜない（聴いた行動だけ） |
| 減衰 | 半減期 30日（長期）／7日（短期、傾向判定用） |
| メーターの見た目 | B'：長さ＋波長（5段階）。4.8以上だけゆっくり流れる |
| 色 | 灰色→5.0に向かって彩度が上がる。アートカラーのテーマなら色相をテーマに合わせる（彩度が低いジャケットは赤橙） |
| 一覧 | ヒート4以上の曲だけ短い波のしるし（動かない） |
| プレイヤー | 文字なし。曲名行の右側にメーター、長押しで Liquid Glass の詳細 |
| 説明文 | 設定の「ヒートメーター」欄だけ |
| タブ切り替え | 方向付きの短いスライド＋フェード（260ms）。「アニメーションを減らす」ではなし |
| Material3 | 1.3.1 → 1.4.0。ui/foundation は 1.10 のまま（1.12 は AGP 9.1 が必要なため見送り） |

## 新規インストール時の初期設定
- 硝子のレンダリング方式：クリア
- ボトムバーをはずませる：ON
- 独立タブをタブバーに統合：ON
- タブバー：ホーム、ライブラリ、フォルダー、検索（起動時はホーム）
- 既存ユーザー：ホームタブを一度だけ先頭に追加（後で隠せば尊重）

## 実装したファイル
- ヒート：`data/stats/Heat.kt`（計算・保存）、`ListeningRecorder`（1回の再生の確定）、`PlaybackService.onMediaItemTransition`（スキップ判定）
- 表示：`ui/components/HeatMeter.kt`（メーター、一覧のしるし、詳細ポップアップ）
- ライブラリ：`feature/library/data/LibraryEntryStore.kt`、`LibraryAddChip.kt`、`LibraryCollectionSections.kt`、`LibraryListContent.kt`
- アーティスト画面の 曲／アルバム／フォルダ 切り替え：`LocalMusicScreen.kt`
- ホーム：`feature/home/ui/HomeScreen.kt`
- 設定：ヒート（あなたのデータ）、ホーム／ライブラリの並び（ローカル音楽 → プレイリストツール）
- バックアップにヒートとライブラリ項目を追加
