## 1. 検索から開いたアルバム／アーティストをライブラリに追加
- **対象**：`feature/localsearch/ui/LocalSearchScreen.kt` の `DrillDownSongList` 呼び出し（289行付近）
- **修正**：ローカル音楽タブと同じく `LocalDrillDownHeaderExtra` で `LibraryAddChip` を渡す。
  - アルバム（`isDrillDownAlbum`）：`type = ALBUM`、アーティストは最初の曲のアルバムアーティスト（なければアーティスト）
  - アーティスト（`isDrillDownArtist`）：`type = ARTIST`
- **ついで**：アーティストの「曲／アルバム／フォルダ」切り替えも、検索から開いた場合に出るようにする。`LocalMusicScreen` の `ArtistPageSwitch` を共通部品に移して使い回す。
- **確認**：検索 → アルバムを開く → 追加 → ライブラリの「アルバム」に出る。アーティストも同様。

## 2. 波線の色と波長をどこでも同じにする
- **色の原因**：`rememberHeatHue()` が `MaterialTheme.colorScheme.primary` から色相を取っている。詳細ポップアップは `GlassContentTheme`（primary が白／黒）の中で描かれるので、彩度が低いと判断されて固定の赤橙になる。プレイヤー側はテーマ色（サーモン）になる。さらにプレイヤーだけ `onArtwork = true` で明るくしている。
- **修正（色）**：
  - 色の計算をテーマから切り離す。`HeatColors`（設定 ＋ アートワーク色）を `CompositionLocal` で一度だけ決め、ガラスの中でも同じ色を使う。
  - 明るさの差（`onArtwork`）もやめる。プレイヤー・詳細・一覧を同じ色にする。
- **波長の原因**：波長が dp 固定なので、長いメーター（詳細 88dp）では山の数が増え、短いメーター（プレイヤー 44dp）とは別物に見える。
- **修正（波長）**：波長を「メーター全体の長さに対する割合」で決める。
  - 段階ごとの山の数を固定する（例：1→1.5山、2→2.5山、3→3.5山、4→5山、5→6.5山、いずれも全長あたり）。
  - 長さが変わっても同じ形の拡大縮小になる。一覧のしるし（`HeatMark`）も同じ規則にする。
- **確認**：プレイヤー、詳細、ホームのカード、一覧のしるしを並べてスクリーンショットで比べる。

## 3. 日付の表示
- 「初めて」「最後」は相対表記にする：今日／昨日／N日前／N週間前／それ以上は `M/d`（年が違うときは `yyyy/M/d`）。
- 1行に収まるよう、セルの文字を少し小さくする（`titleSmall` → `labelLarge`）。

## 4. グラフ：なくすか、意味のあるものに変えるか
**提案：グラフはなくす。** 代わりに数字を 1つ足す。

- **理由**：
  - 「ヒートの推移」は、ほとんどの曲で「今の値まで右肩上がり」か「横ばい」にしかならない（減衰の計算上そうなる）。
  - 初期値から入った曲は履歴がないので、全部同じ形になる。
  - 読み取れることが「上がっている／下がっている」だけなら、矢印 1つで足りる。
- **代わりに入れるもの**：「ピーク」（過去 8週の最大値）と、今との差（例：`ピーク 4.9 · 今 4.7`）。冷めてきた曲だと分かる。
- **もし残すなら**：「週ごとの再生回数（棒グラフ 8本）」にする。そのためには週ごとの再生回数を新たに記録する必要があり、過去の分は 0 になる。

## 5. 初期値の曲で完走率 0%・今週 0 と出る
- 初期値で入った再生回数（`seededPlays`）を別に持つ。
- 完走率 = 最後まで聴いた回数 ÷（再生回数 − 初期値分）。分母が 0 のときは「—」と表示する。
- 「今週」は実際に記録した分だけを数える（今と同じ）。初期値の曲は最初は「0」でよいが、誤解されないよう「—」にする案もある。
- `HeatEntry` に `seededPlays` を追加する。読み込み時に `fullListens == 0 && plays > 0 && recentDays` が空なら、既存データも初期値由来とみなして移行する。

## 6. ホーム・ライブラリのカードで文字が切れる
- **原因**：`Card`（`HomeScreen.kt`）と `LibraryCard`（`LibraryCollectionSections.kt`）で、カード全体（Column）を `clip(RoundedCornerShape(20.dp))` している。左下の角で 2行目の先頭が削れる。
- **修正**：切り抜くのはアートワークだけにする。タップの波紋はカード形にするため `clickable(indication = ripple(), …)` に shape 付きの背景を使う（clip しない）。

## 7. ホームの上部をほかのタブとそろえる
- 大きな「ホーム」の見出しをやめ、ほかのタブと同じ `TabLogoHeader`（左上のロゴ、スクロールで消える）を置く。
- タブ名はガラスのタイトル（統一ルール）に任せる。
- あいさつと「今日／今週」のチップはロゴの下に残す（あいさつを消してチップだけにする案もある）。
- ライブラリと同じく、ロゴが隠れたらタイトルの表示を切り替える（`onTitleScrolledAway`）。

## 8. 並び替えをホーム・ライブラリのタブ上で
- **入口**：各タブのいちばん下に「並びを編集」ボタンを置く。加えて、セクション見出しの長押しでも開けるようにする。
- **編集画面**：`GlassModalBottomSheet` に全セクションを並べる。
  - 各行：表示スイッチ、名前、ドラッグハンドル。上下ボタンも残す（ドラッグが苦手な人向け）。
  - 変更はその場で反映し、閉じるボタンは「完了」だけ。
- **設定画面**：ここからは外す。ホームやライブラリの設定を探す人のため、設定の検索で見つかるようにして、該当タブへ飛ぶ導線だけ残す。
- `SectionOrderDialog` の中身は共通部品（`SectionOrderSheet`）に移す。

## 9. ヒートの色：橙／ピンク／アートカラー
- 設定を ON/OFF から 3択に変更する：`HeatColor { ORANGE, PINK, ARTWORK }`
  - 橙：色相 12°、ピンク：色相 335°付近（明るさは §2 の共通計算）
  - アートカラー：テーマがアートカラーのときはその色相。彩度の低いジャケットは橙に戻す（今と同じ）
- **既定**：初回インストールは `ORANGE` を書き込む（`applyFirstInstallDefaults`）。
  - 更新したユーザーは今の設定を引き継ぐ：保存値がない → 2.5.0 の既定（アートカラーに合わせる）として `ARTWORK` に読み替える。
  - 2.5.0 は昨日入れたばかりなので、更新ユーザーも橙に寄せる案もある（要相談）。
- 設定行：「ヒートの色」→ 3つの色付きの丸から選ぶ（その場で見本の波線も変わる）。

## 10. ヒートの位置：アーティスト名と歌詞バーの間
**提案：賛成。** 曲名・アーティストと一緒に読めて、☆や…ボタンとも競合しない。

- **配置**：
  - 曲名行（固定 60dp）の下、歌詞バー（固定 36dp）の上に、高さ 20dp の行を足す。
  - アーティスト名の書き出しにそろえて左寄せ、幅 56dp。
- **揺れ対策（重要）**：
  - 行の高さは常に固定にする。ヒートが 0 の曲でも行は消さない（灰色の直線を出す）。
  - ヒート機能が OFF のときだけ行ごと消す。OFF の切り替えは設定画面でしか起きないので、再生中に揺れることはない。
  - **この 20dp はアートワークからではなく、下の操作部（再生バー・再生ボタン・音量バーの間の余白）から取る。**
    - まず `controlSpread`（画面の高さに応じて広がる余白）から取る。背の高い画面ではこれで足り、アートワークもボタンの大きさも変わらない。
    - 足りない画面では、再生ボタン上下の固定余白（今は 14dp＋/18dp＋）を下限（例：各 8dp）まで詰める。
    - それでも足りない分だけアートワークから取る。
    - 余白の配分式（`roomy` / `slack` / `controlSpread`）を変えるので、揺れの再確認は必須。
- **対象のレイアウト**：
  - 通常のプレイヤー
  - タブレットの 2カラム（曲名行を操作系の上に寄せた修正と合わせて確認）
  - 歌詞を全面表示しているときの縮んだ見出し：ここでは出さない（今と同じ）
- **長押し**：行全体をタップ範囲にする（今より押しやすくなる）。
- **確認**：曲を 10回スキップして揺れが出ないこと（前回の揺れ修正と同じ測り方：動画から位置を計測する）。
