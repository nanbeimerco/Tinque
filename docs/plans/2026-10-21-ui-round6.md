# UI Round 6 — Implementation plan

対象: Round 5(v2.3.7「Mornyeガラス正式移植・Glass中立色・プレイリスト追加シート・ツールバー縮小」)の実機確認を受けた修正。

実機での評価: Liquid Glass の浮遊部品(メニュー、ツールバー、シート)は、色以外は良好。

---

## Ch1. 浮遊部品は中立色か — 確認結果

### Tinque 方式
- **色相は中立になっている**: タブバーと同じ #121212(ダーク)/ #FAFAFA(ライト)の膜で、文字は白か黒です。アートテーマの色は入っていません。
- **暗く見える原因は「膜の濃さ」**: 部品ごとに膜の不透明度が違っていました。

| 部品 | 膜の不透明度(ダーク時は黒の濃さ) |
|---|---|
| タブバー・ミニプレーヤー | 40%(設定の「不透明度」の値) |
| 選択ツールバー | 55% |
| 3点メニュー | 72% |
| プレイリスト追加シート・ダイアログ | 78% |

文字を読みやすくするために固定値で濃くしていたので、タブバーよりはっきり黒くなっていました。

### Mornye 方式
- **中立色が Mornye とずれていた**: Tinque の中立色を流用していました。

| | Mornye 本体 | Tinque(Round 5) |
|---|---|---|
| ダークの膜の元の色 | #2C2C2E | #1C1C1E(より黒い) |
| ライトの膜の元の色 | #F2F2F7 | #EDEDF2 |

### 対応
1. **Mornye 方式の中立色を Mornye の値(#2C2C2E / #F2F2F7)にする。**
2. **Tinque 方式の浮遊部品の濃さを、タブバーに揃える**(決定 T)。
   - 膜は「設定の不透明度 + 15%」(既定値なら 40% → 55%)にします。
   - 読みやすさは濃さではなく**ぼかしを 1.5 倍**にして確保します。
   - メニュー、シート、ツールバーはすべてこの規則にします。
3. Liquid Glass が使えないときの代わりの塗りも、同じ中立色(Tinque: #1C1C1E / #F2F2F5、Mornye: #2C2C2E / #F2F2F7)にそろえます。

## Ch2. Mornye 方式が暗い・黒い、選択ピルが浮く

### 原因
- **Mornye 本体の設計がもともと暗い**: ダークでは、膜の下に黒 35% を敷いています(明るいアートワーク対策)。タブバーの実質的な暗さは約 54% になり、真っ黒寄りに見えます。
- **Mornye はアートテーマのとき膜を薄くしている**: タブバー 0.36 → 0.24、ミニプレーヤー 0.60 → 0.36。Tinque の移植では、この切り替えを入れていませんでした。そのため、M3 Expressive のアートカラーモードでも暗いままでした。
- **選択ピルが Tinque の値のまま**: Mornye 方式でも、選択中タブのピルに Tinque の乳白色(白 約 24%)を使っていました。Mornye の止まっているピルは**白 12%(ダーク)/ 黒 8%(ライト)+ 0.5px の淡い縁**なので、Tinque の方が白く浮いていました。

### 対応
1. **アートテーマでは Mornye 自身のアートテーマ用の濃さを使う**(タブバー・上部ボタン 0.24、ミニプレーヤー 0.36)。色は中立のままです(コンセプトどおり、アートの色には染めません)。
2. **「ガラスの暗さ」スライダーを追加**(Mornye 方式のときだけ、クリアさの下に表示)。
   - 膜の下に敷く黒の量(0〜35%)と、膜の濃さを一緒に調整します。
   - 0% で最も明るく澄んだガラス、100% で Mornye 本体と同じになります。
   - 既定値は決定 U。
3. **選択ピルを Mornye の値にする**: 止まっているときは白 12% / 黒 8% + 淡い縁。押している間だけ白 8% / 24% のレンズになります。

## Ch3. プレイリスト追加シートにアルバムアートが出ない

### 原因
Round 5 で作り直したとき、各プレイリストの行のアイコンを、元のシートと同じ汎用アイコン(♪の並び)にしていました。プレイリストのカバー(`customCoverUrl` → なければ `coverUrl`)を読んでいませんでした。

### 対応
- 各行の左を **44dp・角丸 12dp のカバー画像**にします。読み順はライブラリと同じで、ユーザーが選んだ画像 → 曲から自動で取ったアート。どちらもないときだけ汎用アイコンにします。
- 「新しいプレイリスト」の行は、今のまま ＋ アイコンにします。

---

## Ch4. 選択中、3点ボタンが消えて曲の長さが右端に寄る

### 原因
選択モードでは 3点ボタン(幅 36dp)を消していました。そのぶん、曲の長さ(3:32 など)が右端まで寄ります。選択の出入りのたびに右側の並びがずれるので、ぎこちなく見えます。フォルダタブだけでなく、曲タブや詳細ページの行でも同じです。

### 対応
- 選択中も、**3点ボタンと同じ幅(36dp)の場所は確保したまま**、中身だけを消します(フェード)。曲の長さの位置は選択の前後で変わりません。
- 選択中にその場所を押しても何も起きないようにします(行のタップで選択が切り替わる)。

## 決定事項(T・U とも推奨案で確定)

| # | 論点 | 推奨 | 代替 |
|---|---|---|---|
| **T** | Tinque 方式の浮遊部品の膜の濃さ | **設定の不透明度 + 15%、ぼかし 1.5 倍**(タブバーと同じ見た目で、読みやすさはぼかしで出す) | タブバーと完全に同じ(文字が背景に負けることがある) |
| **U** | Mornye 方式の「ガラスの暗さ」の既定値 | **50%**(黒の下敷き 17.5%)。Mornye 本体の雰囲気は残しつつ、黒さを抑える | 100%(Mornye 本体と同じ) |

## Ch5. 浮遊 UI 20 か所の Liquid Glass 化(Round 5 のバックログ)
ユーザーの指示で、このラウンドで実装する。

### 方針
- **置き換え用の共通部品**を作り、各画面は呼び出しを差し替えるだけにする。
  - `GlassModalBottomSheet`: `ModalBottomSheet` の代わり
  - `GlassAlertDialog`: `AlertDialog` の代わり
  - `GlassDropdownMenu`: `DropdownMenu` の代わり
- **ガラスの中は中立色の M3 テーマ**で描く。ガラスの上だけ `MaterialTheme` の色を中立色(`GlassPalette`)に差し替える。こうすると、中の既存の M3 部品(文字、ボタン、入力欄、メニューの行、スライダー)が、アート色に染まらず自動で中立色になる。
- **別ウィンドウの中では自動で M3 に戻す**。ホストがアプリのウィンドウ(`View`)を覚えておき、呼び出し元の `LocalView` が違えば(再生画面、イコライザー、タグ編集などの中)、今まで通りの M3 部品で表示する。ガラスが後ろに隠れて見えなくなることがない。
- 対象外: 再生画面そのもの(ページ)。

### 実装メモ
- 共通部品は `ui/components/GlassFloating.kt`(`GlassModalBottomSheet` / `GlassAlertDialog` / `GlassDropdownMenu` / `GlassContentTheme` / `GlassWindowScope`)。
- 別ウィンドウの画面(タグ編集、歌詞エディター、イコライザー、再生画面)は、`GlassWindowScope` で専用のガラスの土台を持たせた。中で開くシート・ダイアログ・メニューもガラスになる。土台が描画を記録するのは、何かが開いている間だけ。
- MainActivity の曲操作シートは、再生画面の上から開いたときだけ M3 に戻す(ガラスが再生画面の後ろに隠れるため)。
- 置き換えた場所: バックログの 1〜20 に加えて、MainActivity のダウンロードマネージャー、オンラインのプレイリスト選択、ブラウズ操作シート、アルバムアート一括取得のダイアログ。
- 対象外のまま: 再生画面そのもの、再生速度・ピッチのシート(再生画面の一部)、Replay の共有シート。
