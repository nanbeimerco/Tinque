# UI Round 4 — Implementation plan

対象: Tinque (v2.3.7 の次)。ミニプレーヤーのスワイプ仕上げ、選択モードの作り直し、フォルダタブの操作統一、3点メニューの Liquid Glass 化、設定タイトル、フォルダのロゴ位置、Liquid Glass の Mornye 方式レンダリング(オプション)。

---

## Ch1. ミニプレーヤー: スワイプ時の切れ目が直線

### 原因
`MiniPlayerTrackSwipe` が `clipToBounds()` で**長方形**に切っている。この領域はバー内側の padding(12dp / インライン 8dp)の内側にあるので:
- 左端: バーはカプセルで丸いのに、内側の直線で曲が消える。
- 右端: 再生ボタンの手前で、くっきりした縦の線で切れる。

### 対応
1. **左端はバーの形で切る**: スワイプ領域を外側の padding の分だけ左へ広げる(内容は同じ padding で元の位置に戻す)。クリップはバーと同じカプセル形状にする。曲はバーの丸い端に沿って消える。
2. **右端はフェード**: 長方形クリップをやめ、右端 20dp を透明へのグラデーションマスク(`CompositingStrategy.Offscreen` + `BlendMode.DstIn`)にする。曲は次第に消えながらボタンの下へ入っていく。
   - マスクは**ドラッグ中だけ**かける。静止時は文字の末尾が薄くならない(省略記号 … はそのまま)。
3. 対象は `GlassNavBar.kt`(タブバー一体型/インライン)と `MiniPlayer.kt`(従来型)の両方。

## Ch2. ミニプレーヤー: スワイプ中に高さが変わる

### 原因
スワイプ領域の `Box` は、現在の曲と隣の曲の**高い方**に合わせて伸びる。曲名・アーティスト名の文字種(日本語のフォールバックフォント、カスタムフォント、絵文字など)で行の高さが 1〜数 px 違う。そのため、隣の曲が入ってきた瞬間にバー全体の高さが変わる。普通の曲送りでも同じことが起きているはず。

### 対応
1. **文字の行を固定の高さにする**: タイトル・アーティストの各行を、タイポグラフィの `lineHeight` から計算した固定の高さに入れる。`LineHeightStyle(Alignment.Center, Trim.None)` で上下中央に揃え、文字種で高さが変わらないようにする。
2. **スワイプ枠は表示中の曲だけで寸法を決める**: カスタム `Layout` で、現在の曲のページだけで高さを決める。隣のページは同じ制約で測って横に並べる(はみ出した分は切る)。万一高さが違っても、バーは動かない。

## Ch3. 選択モードの作り直し(アルバム/曲タブ)

### 現状の問題
- 長押しすると `DownloadSelectionBar` がリスト上部に**帯**として挿入される。上には上部バー分の余白がすでにあるので、リスト全体が 1 行分下へずれる。
- 帯は 44dp の固定高で、「N 選択済み」「プレイリストに追加」「キャンセル」を横に詰めている。日本語だと折り返して**表記が崩れる**。
- 選択中の行は「背景が薄く primary 色になる + 右端の小さなチェック」だけ。どれを選んだか分かりにくい。選択モードに入ったこと自体も分かりにくい。
- 「全選択」はチェックアイコンだけで、意味が伝わらない。

### 新デザイン(M3 Expressive 準拠、帯なし)
**上部(固定バーなし。既存の浮遊ガラス部品を使う)**
- 左のガラスボタン → **×(選択解除)**
- 中央のタイトルカプセル → **「3 曲を選択中」**
- 右のガラスボタン → **全選択 / 全解除**(トグル。Ch4)
- 戻る・設定・並べ替えボタンは、選択中は隠す。

**下部: 浮遊アクションツールバー(M3 Expressive の Floating toolbar)**
- ミニプレーヤー/タブバーの上に、カプセル型の Liquid Glass ツールバーを浮かべる。
- 項目(アイコン + 短いラベル): **次に再生 / キューに追加 / プレイリストに追加 / (削除)**。削除はダウンロードやプレイリスト内のときだけ表示する。
- 選択数が 0 になったら選択モードを抜ける。

**行の見た目**
- リスト行
  - 選択中は、行全体を `secondaryContainer` の角丸(16dp)コンテナにする(左右 8dp 内側に入れる)。
  - アートワークは少し縮み(0.86 倍、spring)、上に丸いチェックバッジが乗る。
  - 選択モード中は、未選択の行のアートワークにも空の丸を出す。「タップで選択」と分かるようにする。
- グリッドカード(曲/アルバム): Google Photos 風。選択中はアートの角丸が大きくなりながら縮み、左上にチェックバッジを出す。
- 選択の出入りと切り替えは、すべて spring アニメーションにする。

### 実装の形
- `SongSelectionState`(新規。選択 ID の集合、選択順を保つ曲リスト、全選択の対象 = 現在の階層の曲)を MainActivity が持つ。`LocalSongSelection` で配る。
- 上部の選択ヘッダーと下部ツールバーは MainActivity が描く(戻る/設定ボタンと同じ層)。
- `LocalMusicScreen` は独自の `selectedSongIds` をやめて共有状態を使う。アルバム単位の選択(`selectedAlbumKeys`)の考え方はそのまま残す。
- タブ切り替え・階層移動・戻るボタンで選択を解除する。
- `DownloadSelectionBar` は削除する。

## Ch4. その階層の曲をすべて選択

- 選択中、右上のガラスボタンで、**今表示している階層の曲をすべて選択**する。全部選ばれていれば「全解除」になる。
- 「階層」が指すもの:

| 画面 | 全選択の対象 |
|---|---|
| 曲タブ | 全曲(現在の並び順) |
| アルバム/アーティスト詳細 | その中の全曲 |
| アルバムタブ一覧 | 全アルバムの曲(アルバム単位で選択済みにする) |
| フォルダ(曲が入っている階層) | そのフォルダの曲 |
| フォルダ(途中の階層) | **決定 L** |

## Ch5. フォルダタブ: 長押しで複数選択、3点で曲メニュー

### 現状
- フォルダタブの曲の長押しは `openSongMenu`(曲操作シート)を開く。選択モードがないので、1 曲にしか操作できない。
- フォルダの曲の行には 3点ボタンがない(`songDropdownMenu` が渡されていない)。

### 対応
- **長押し → 選択モード**(Ch3 と同じ共有状態)。途中の階層の曲の行と、曲だけの階層(`DrillDownSongList`)の両方で。
- **フォルダ行の長押し → そのフォルダ以下の曲をまとめて選択**。アルバムの長押しでアルバムの曲をまとめて選ぶのと同じ考え方。
- **3点ボタンを追加 → 曲メニュー(Ch6)**。今の長押しで開いていたメニューへの入口はここになる。
- 選択中に下部ツールバーの「プレイリストに追加」を押すと、他のタブと同じ追加ダイアログを開く。

## Ch6. 3点メニューを Liquid Glass に(全タブ共通)

- M3 の `DropdownMenu`(不透明、`surfaceContainerHigh`)をやめ、新しい **`GlassSongMenu`** にする。
  - 3点ボタンの位置から開くポップアップ。中身は**ウィンドウ内のオーバーレイ**として描く(別ウィンドウの Popup だとガラスの背景を取得できないため)。オーバーレイはルートの `LocalAppBackdrop` を取得して本物の Liquid Glass を描く。ガラスが無効な端末では `lightweightLiquidGlass` を使う。
  - 角丸 24dp。行は 48dp、アイコン + ラベル。区切りは隙間 + 細い線(M3 Expressive のメニュー グループ)。
  - 開くときは、ボタンを起点にした拡大 + フェード(spring)。閉じるときは逆の動き。外側をタップすると閉じる。
  - 「移動 ▸」の階層は、同じカプセル内で横にスライドして切り替える(今の「中身だけ入れ替え」をアニメーション化)。
- 項目は**決定 M**。
- 適用先: 曲タブ、アルバム/アーティスト詳細、フォルダ(Ch5)、プレイリスト詳細。
- 再生画面の曲操作シート(`LocalSongActionsSheet`)はそのまま残す。プレイヤー専用の項目(イコライザー、スリープタイマー)があるため。

## Ch8. フォルダタブのロゴが内側に寄っている

### 原因
`TabLogoHeader` 自体がロゴを `start = 20dp` に置くが、フォルダの `LazyColumn` には `contentPadding(start = 16.dp)` がある。そのため、フォルダタブだけ 16dp 内側にずれる。

### 対応
- `TabLogoHeader` に `horizontalInset: Dp = 0.dp` を追加する。フォルダ画面から `16.dp` を渡すと、その分だけ左へ戻して描く(幅もその分広げる)。
- ほかの画面で同じ種類のずれがないか確認する(検索、ライブラリ、曲/アルバム/アーティストのリストとグリッド)。

## Ch9. Liquid Glass のレンダリング方式に「Mornye 方式」を追加

### 解析: Mornye のガラスはどう描かれているか
Mornye は Flutter 製のアプリです。ガラスは `liquid_glass_easy` 5.0.0 パッケージの `LiquidGlassLens` を、薄いラッパー `lib/widgets/mornye_liquid_backdrop.dart` と `lib/widgets/mornye_chrome.dart`(`MornyeGlass`)で包んで使っています。シェーダー本体はパッケージ側の `liquid_glass.frag` です。中身は手元にあった 4.3.2 で読みました。5.0.0 は手元にないので、パラメーターの意味は Mornye 側のコードと突き合わせて確認しています。

描画は次の順で行われます。

1. **背後を直接読む**: Impeller の `BackdropFilter` を使い、ガラスの真後ろに既に描かれている画面をそのまま入力にします。録画用のレイヤーはありません。解像度は**等倍**です。
2. **先にぼかす**: Gaussian ブラーを 1 回かけます。強さは「クリアさ」(clarity、既定 0.75)で決まり、σ = 2 / 3 / 6 / 16 の 4 段階です。既定値では **σ = 6、弱め**になります。このブラーと屈折は 1 回の背景読み取りにまとめて処理されます(`LiquidGlassBatch`)。
3. **光学レンズで屈折**: 縁の内側 **約 20px の帯だけ**、スネルの法則で光を曲げます(屈折率 ≈ 1.07)。**内側は拡大も歪みもない**ので、背景がほぼそのまま見えます。
4. **分散(色にじみ)**: 曲がる帯の中だけに入れ、縁に近いほど強くします。ずらす量は画素の明るさに比例します(明るい所ほど虹色に割れる)。幅は 1.32 × clarity px です。
5. **色の膜(tint)**: clarity が高いほど、`surfaceContainerHigh` の濃い膜から「澄んだ膜」に近づきます。澄んだ膜は、ダークで #999999 の 17%、ライトで白の 46% です。ダークでは明るいアートワーク対策として黒 35% を下地に混ぜます。アートワークテーマ中は、カバーの色相を彩度 1.6 倍にした膜にします。
6. **光**: 縁の上部に**細い鏡面ハイライト**(spread 0.2、強さ ダーク 0.25 / ライト 0.12)を引き、外側に**淡いグロー**を加えます。影は外側に 8px・下 2px の柔らかいものです。
7. **端末の性能に応じて段階を落とす**: liquid(屈折あり)→ frosted(ブラー + 膜のみ)→ flat(不透明)。

### Tinque の今の方式との違い

| | Tinque(現在) | Mornye |
|---|---|---|
| 背景の取り方 | アプリの画面をレイヤーに**録画**して描き直す(Kyant0/backdrop) | 後ろの画面を**直接**読む |
| 解像度 | **1/3** に縮小して処理 | 等倍 |
| 下ごしらえ | 彩度 1.5 倍 → ブラー 8dp(ユーザー設定) | 彩度そのまま → 弱いブラー(σ 6) |
| 屈折 | 縁から 24dp の帯で強く曲げ、奥行き効果あり | 細い 20px の帯で、物理的な屈折率で控えめに曲げる。内側は無変形 |
| 色にじみ | 帯の中で一定量 | 明るさに比例し、縁ほど強い |
| 膜 | #121212 / #FAFAFA を不透明度 40%(設定) | clarity で「濃い膜 ↔ 澄んだ膜」を補間 |
| 縁の光 | Kyant の既定ハイライト | 細い鏡面 + 淡いグロー |

見た目の差としては、Tinque は「ふわっと乳白で、全体がやわらかく歪む」ガラスです。Mornye は「中は澄んでいてくっきり、縁だけがレンズのように光を曲げる」ガラスです。

### Tinque での実現方法
Android には Flutter の `BackdropFilter` にあたる「背後の画面を直接読む」API がありません。そこで、**背景の取り方は今の録画方式(`LocalAppBackdrop`)のまま**にして、**その上の処理を Mornye 方式に差し替えます**。

1. **新しい AGSL シェーダー `OpticalLensShader`**: `liquid_glass.frag` の光学屈折(`REFRACTION_OPTICAL`)、帯の中だけの明るさ比例の分散、鏡面ハイライトとグローを AGSL に移植します。Android 13 以上(`RuntimeShader`)が対象です。パッケージのライセンス表記(「Free to use in any project」)に従い、出典をファイル冒頭に記します。
2. **`liquidGlass()` に方式の分岐を入れる**: Mornye 方式のときは、効果の順番を「ブラー(clarity から σ)→ 光学レンズ」にします。彩度の強調はかけません。
3. **解像度**: Mornye 方式では 1/3 → **1/2** にします。内側がくっきり見える方式なので、1/3 だと粗さが目立ちます。等倍は、ガラスが最大 6 枚同時に動く畳み動作で重くなるため避けます。1/2 で重さを実機計測し、問題があれば 0.4 まで下げます。
4. **膜と影**: `onDrawSurface` を Mornye の膜の計算式に、ハイライトを鏡面 + グローに、影を Mornye の値に切り替えます。
5. **対象**: すべての `liquidGlass` 表面(タブバー、ミニプレーヤー、上部のガラスボタン、タイトルカプセル、Ch3 のツールバー、Ch6 のメニュー)。タブバーの移動する選択ピル(`GlassSelectionPill`)は、Mornye と同じく「ブラー 0・clarity 1 のレンズ」にします。
6. **軽量版と非対応端末**: `lightweightLiquidGlass` は、方式に合わせて膜の色の計算だけ切り替えます。Android 12(API 31〜32)では屈折シェーダーが使えないので、ブラー + 膜までにします(Mornye の frosted 相当)。

### 設定画面
- 外観 → Liquid Glass に **「レンダリング方式: Tinque / Mornye」** の切り替え(SegmentedControl)を追加します。
- Mornye を選ぶと、今の「ぼかし」「不透明度」スライダーの代わりに **「クリアさ」スライダー**(0〜1、既定 0.75)を表示します(決定 P)。
- 切り替えると、その場で全部のガラスが描き変わります(再起動は不要)。

## 確認方法
- ミニプレーヤー: 日本語・英語・絵文字の曲が混ざったキューでスワイプする。左はバーの丸に沿って消え、右はフェードし、高さが動かないこと(両方の形式で)。
- 選択: 曲/アルバム/アーティスト詳細/フォルダの 2 種類の階層で、長押し → 追加選択 → 全選択 → プレイリストに追加。帯が出ず、リストがずれないこと。戻る・タブ切り替えで解除されること。
- 3点メニュー: 各タブで開き、ガラスが背景を映すこと、「移動 ▸」の切り替えアニメーション、画面端での位置補正。
- 設定のカプセル表示と、フォルダのロゴ位置(他タブと並べて比較)。
- ビルドして `release_apk\<version>_<内容>\` に配置する。
