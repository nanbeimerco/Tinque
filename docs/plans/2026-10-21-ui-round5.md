# UI Round 5 — Implementation plan

対象: Round 4(v2.3.7「選択モード刷新・Glassメニュー・Mornye風ガラス・スワイプ端修正」)の次。

**コンセプト(今回から明文化)**
- 画面の基本は Material 3 Expressive。
- **浮かんで出てくるもの**(メニュー、シート、ツールバー)と、**常駐する浮遊部品**(タブバー、ミニプレーヤー、上部のボタン)は Liquid Glass。
- Liquid Glass の色はアートテーマに染まらず、タブバーと同じ中立色にする。

---

## Ch1. Mornye 方式のガラスは本当に Mornye と同じか — 検証結果と修正

### 結論: 同じになっていない
Round 4 の移植は、手元にあった `liquid_glass_easy` **4.3.2** のシェーダーと、Mornye 側のパラメーターから推定して作ったものです。Mornye が使っているのは **5.0.0** です。今回、5.0.0 の配布元(GitHub `AhmeedGamil/liquid_glass_easy` の `liquid_glass_common.glsl` ほか)を確認したところ、次の **6 点**で食い違っていました。

| # | 項目 | Mornye(5.0.0 の実装) | Tinque の Round 4 移植 | 影響 |
|---|---|---|---|---|
| 1 | **屈折の計算式** | 縁の帯の中で 3D 法線 `normalize(n2D·√(1−h²), h)` を作り、`refract(I, N, 1/n)` の xy 成分 × **固定 70 論理px** × zoneT だけずらす。縁でのずれは `√(1−1/n²)·70` ≈ **約 24px** | 自前の「傾き → スネルの偏角 → tan × 帯幅」。縁でのずれは **約 7px** | **縁の曲がりが約 1/3 しかない**(一番大きな差) |
| 2 | **部品ごとの曲がりの強さ** | `refractionDepth` から屈折率を逆算している。タブバー 0.45〜0.60(n≈1.17)、ミニプレーヤー・ボタン 0.30(n≈1.07)、選択ピル 0.18 / 幅 18(n≈1.02) | 全部の部品で n=1.066 / 幅 20 | タブバーの縁が弱すぎる |
| 3 | **膜(tint)の濃さ** | タブバー・ミニプレーヤーなどは `strongTint` で、「澄んだ膜」には寄せない。不透明度は部品ごとの固定値(ダーク: タブバー 0.36、ミニプレーヤー 0.60 / ライト: 0.49、0.70。アートテーマ中は 0.24、0.36) | 全部品で「澄んだ膜」に寄せる式を使っている | バーが Mornye より白っぽく透ける |
| 4 | **色にじみ** | ずらす方向は**斜め固定**(`vec2(shift·luma)`)。0.66px 未満なら何もしない | 法線方向にずらす、しきい値なし | にじみの見え方が違う |
| 5 | **縁の光** | 縁の 4px ほどに、**後ろの色を拾って明るくした光**を重ねる(白ではない)。角度 0、広がり 0.2 で左右 2 か所の弧に集中する。強さはごく弱い。**膜より上**に描く | Kyant の白い加算ハイライト(45°、1dp、α0.55)。膜より上 | Tinque の方が白く、くっきり光る |
| 6 | **解像度** | 等倍 | 1/2 | 中の背景の精細さ |

ぼかしの強さ(clarity から σ 2/6/16)、影(8px・下 2px)、`LiquidGlassBatch` による「ぼかしと屈折を 1 回の読み取りにまとめる」点は一致しています。

### 修正内容
1. **シェーダーを 5.0.0 の式に置き換える**(`OpticalLens.kt`)
   - 屈折: 3D 法線 + `refract()` + 70dp × zoneT。zoneT は縁で 1、帯の内側で 0 です。
   - 色にじみ: 斜め方向、0.66dp 未満は無効、帯の中だけ zoneT で強くする。
   - 彩度: Mornye は指定していないので 1(そのまま)。
2. **膜と縁の光をシェーダー内に移す**: 5.0.0 は「サンプル → 膜を混ぜる → 縁の光を上に重ねる」を 1 回で処理しています。Tinque でも膜の色をシェーダーに渡し、`onDrawSurface` の塗りと Kyant のハイライトは使わないようにします。縁の光は「後ろの色を拾って明るくする」方式で、角度・広がり・強さを Mornye の値で再現します。
3. **部品ごとの役割(`GlassRole`)を追加**: `liquidGlass(shape, role = …)` で、Mornye 方式のときだけ次の値を使います。Tinque 方式は今までと同じです。

| role | 使う場所 | 曲がり(depth → n) | 膜 |
|---|---|---|---|
| `TabBar` | タブバー | 0.45(押している間 0.60) | strong・0.36 / 0.49 |
| `Player` | ミニプレーヤー | 0.30 | strong・0.60 / 0.70 |
| `Control` | 上部の丸ボタン、タイトルカプセル | 0.30 | strong・0.36 / 0.49 |
| `Overlay` | メニュー、シート、選択ツールバー | 0.30 | strong・0.78 |
| `Pill` | タブバーの選択ピル | 0.18・幅 18、ぼかし 0 | 白 0.08 / 0.24 |

4. **解像度**: 決定 R。
5. **確認方法**: 同じアルバムアートを開いた状態で、Mornye と Tinque(Mornye 方式)のスクリーンショットを並べてください。私は実機を見られないので、比べた結果をもらえれば、縁の曲がり・光・膜の濃さを詰めます。

## Ch2. Liquid Glass の色をアートテーマから切り離す

### 原因
- **3点メニュー**: 文字とアイコンが `colorScheme.onSurface` で、アートテーマのときはアートの色に染まります。削除の赤も `colorScheme.error` です。Liquid Glass が使えないときの代わりの塗りも `surfaceContainerHigh`(アート色)です。
- **選択ツールバー**: 代わりの塗りが `surfaceContainerHigh` です。
- **Mornye 方式の膜**: `surfaceContainerHigh` を使っているので、アートテーマ中はアート色になります。
- 一方タブバーは、膜が中立の #121212 / #FAFAFA、文字が白(ダーク・アートテーマ)/ 黒(ライト)です。

### 対応
- 共通の **`GlassPalette`** を作ります。タブバーと同じ規則で、次の色を返します。
  - `content`: 白 / 黒
  - `secondary`: 70%
  - `divider`: 14%
  - `destructive`: システムの赤 #FF453A / #FF3B30
  - `fallbackFill`: Liquid Glass が使えないときの塗り(中立のダークグレー / ライトグレー)
  - `mornyeContainer`: Mornye 方式の膜の元にする中立色
- メニュー、ツールバー、Ch3 のシート、上部のボタン、タイトルカプセルは、すべて `GlassPalette` を使います。
- 例外: タブバーの選択中タブの色だけは、今まで通りアートのアクセント色を使います(既存の挙動)。ガラスの中に置くアクセントはこれだけにします。

## Ch3. 「プレイリストに追加」を Liquid Glass のシートに

### 現状
`LocalAddToPlaylistSheet` は M3 の `ModalBottomSheet` で、画面の下に張り付いた不透明な面です。しかも `ModalBottomSheet` は**別ウィンドウ**なので、そのままでは後ろの画面を取得できず、Liquid Glass にできません(Round 4 のメニューと同じ理由)。

### 対応
- **`GlassSheetHost` を追加**: メニューの `GlassMenuHost` と同じく、アプリのウィンドウ内の最前面に描きます。
  - **浮遊シート**: 左右と下を 10dp あけ、角丸 32dp。下から spring で上がってきます。
  - 後ろは 32% の暗幕。暗幕をタップするか、下へのドラッグ、戻る操作で閉じます。
- **中身は M3 Expressive のまま**: 見出し + 閉じるボタン、グループ化したリスト(「新しいプレイリスト」行、既存のプレイリスト一覧)。色は `GlassPalette` を使います。
- そこから開く**「新しいプレイリスト」ダイアログ**も、同じホストで中央に浮かぶ Liquid Glass のカードにします。
- `LocalAddToPlaylistSheet` の引数は変えずに、中身だけ差し替えます。曲の 3点メニュー、選択ツールバー、フォルダ画面、ライブラリのどこから開いても同じ見た目になります。
- 他の浮遊 UI をどこまで今回やるかは、**決定 Q**。

## Ch4. 選択ツールバーをアイコンだけのコンパクトな形に

### 現状の問題
- 各ボタンが「アイコン + ラベル」で、幅 64〜84dp・高さ約 56dp と大きい。
- 「再生キューに追加」が長く、末尾が「…」になる。
- 幅が文字の長さでばらつくので、真ん中のボタンが中央に来ない。

### 対応(M3 Expressive の Floating toolbar・アイコンのみ型)
- **アイコンだけの円形ボタン**(48dp タッチ領域、アイコン 24dp)を等間隔に並べ、カプセルの高さは **56dp → 52dp**。
  - ボタンがすべて同じ幅になるので、全体が中央にそろいます。
- 並び: **次に再生 / キューに追加 / プレイリストに追加 / (削除)**。削除だけ赤にして、細い区切りで分けます。
- **意味が分からないときの補助**:
  - 長押しで、ボタンの上にガラスの小さな吹き出し(ツールチップ)で名前を表示します。
  - 読み上げ用の説明(contentDescription)は今まで通り付けます。
- 選択数は上のカプセル(「3 曲を選択中」)に出ているので、ツールバーには入れません。

## 次回以降に Liquid Glass 化する浮遊 UI(バックログ)
今回作る `GlassSheetHost` に、優先度の高い順に載せ替える。どれも今は別ウィンドウの M3 部品(`ModalBottomSheet` / `AlertDialog` / `Dialog` / `DropdownMenu`)。

**優先度 高**(よく使う)
1. 並べ替えシート — `LocalSortBottomSheet`
2. 曲の詳細 — `LocalSongDetailsSheet`
3. 曲の削除の確認 — `LocalDeleteConfirmDialog`
4. 曲の操作シート(再生画面の長押し) — `LocalSongActionsSheet`
5. アーティストの選択 — `LocalArtistPickerSheet`
6. プレイリスト / フォルダの行の ⋮ — `LocalPlaylistItem`、`LibraryPlaylistCard`、`LocalFolderItem`
7. アーティストの並べ替えメニュー — `ArtistViewAndSortControls`

**優先度 中**
8. ライブラリのプレイリスト名の変更・削除 — `LibraryScreen` 内の `AlertDialog` / `DropdownMenu`
9. 保存したキュー — `SavedQueuesDialog`
10. 除外フォルダの管理 — `BlacklistedFoldersSheet`
11. 歌詞のダウンロード — `LyricsDownloadSheet`、`LyricsDownloadDialog`
12. 歌詞の検索結果 — `LyricsSearchResultsSheet`、`LyricsSearchResultsDialog`
13. 歌詞の選択 — `LyricsSelectorDialog`
14. 歌詞エディターの上部メニュー — `LyricsEditorBottomBar`
15. MainActivity のダウンロードマネージャー、オンラインのプレイリスト選択(`PlaylistPickerSheet`)

**優先度 低**(たまにしか出ない)
16. 音声カット — `AudioCutterSheet`
17. タグ編集のジャンル・画像の選択 — `TagEditorGenreDialog`、`TagEditorImageOptionsDialog`、`TagEditorTopBar`
18. 権限のお願い — `AllFilesPermissionDialog`
19. イコライザーの中のダイアログ — `EqualizerSheet`、`ParametricAudioControls`
20. 設定画面の中のダイアログ — `SettingsSheet`
