# 再生コントロールアイコン調整 実装計画書

作成日: 2026-10-21 / 対象: Tinque 2.3.7(`com.music.tinque`)

## 要望
1. 曲戻し/曲送りの2つの三角の重なりを、参考画像のように**かなり浅く**する。
2. 停止(一時停止)ボタンの縦線を、それぞれ**やや細く**する。
3. ボトムバーの縮小ミニプレーヤーにも、新しい曲戻し/曲送り/再生/停止アイコンを使う。
4. ミニプレーヤーで、再生/停止ボタンが曲戻しボタン側に寄って見える問題を直す。

---

## 調査結果

### 1. 三角の重なりが浅くならなかった理由
アイコン([BitChordIcons.kt](../../app/src/main/java/com/music/bitchord/ui/icons/BitChordIcons.kt) の `skipIcon()`)は、三角形の塗りの上に **幅2.6の丸い線** を重ねて角を丸めている。この線は図形の外側に **1.3 ずつはみ出す**。

- 後ろの三角の先端は 1.3 右へ、前の三角の底辺は 1.3 左へ広がる。
- そのため、**見た目の重なり = 座標上の重なり + 2.6** になる。

| | 座標上の重なり | 見た目の重なり(24単位中) |
|---|---|---|
| 初回 | 4.2 | 約 6.8 |
| 前回の修正後 | 1.4 | 約 4.0 |
| **今回の目標** | −2.0(座標上は離す) | **約 0.6** |

前回は座標だけ浅くしたため、見た目はほとんど変わっていなかった。

### 2. 停止ボタン
現在の縦線は幅 6.5、間隔 2.2(高さ 16)。参考画像は、線の幅が高さの約0.36、間隔が約0.17。

### 3・4. ミニプレーヤー
ボトムバーのミニプレーヤーは2か所に実装がある。

- [GlassNavBar.kt](../../app/src/main/java/com/music/bitchord/ui/components/GlassNavBar.kt) の `GlassNowPlaying`:現在の標準(折りたたみ式ボトムバー)。
- [MiniPlayer.kt](../../app/src/main/java/com/music/bitchord/ui/components/MiniPlayer.kt):旧式(設定でクラシックなボトムバーを選んだとき)。

どちらも Material 標準のアイコン(`SkipPrevious` / `Pause` / `PlayArrow` / `SkipNext`)のままだった。

**寄って見える原因**:どちらの実装も、ボタンの並びが次のようになっている。

```
[曲戻し][再生/停止][隙間 8dp][曲送り]
```

隙間が再生ボタンと曲送りの間にしかないため、再生ボタンが曲戻し側にくっついて見える。さらに旧アイコンの `SkipPrevious` は左端に縦棒があり、見た目の重心が左に寄っている。

## 変更内容

### A. アイコン形状([BitChordIcons.kt](../../app/src/main/java/com/music/bitchord/ui/icons/BitChordIcons.kt))
- **曲送り/曲戻し**(`skipIcon`)
  - 後ろの三角:底辺 1.5 → 先端 10.9
  - 前の三角:底辺 12.9 → 先端 22.3
  - 2つの三角は同じ幅(9.4)、高さは今のまま(5.4〜18.6)、角丸の線幅 2.6 も今のまま。
  - 見た目の重なりは約 0.6 で、先端がわずかに食い込む程度になる。全体の横幅は約 0.2〜23.6 に収まる。
- **停止**(`TransportPause`)
  - 縦線の幅を 6.5 → **5.4** に細くする。
  - 間隔を 2.2 → **2.6**(参考画像の比率に合わせる)。
  - 位置:左の線 5.3〜10.7、右の線 13.3〜18.7。高さ 4〜20、角の丸み 1.3 は今のまま。
- 再生ボタン(`TransportPlay`)は変更しない。

この変更は、再生画面・歌詞画面・スワイプ時のヒント表示など、新アイコンを使っている全箇所に自動で反映される。

### B. ミニプレーヤーに新アイコンを適用
`GlassNowPlaying`(GlassNavBar.kt)と `MiniPlayer`(MiniPlayer.kt)の両方で置き換える。

| 旧 | 新 |
|---|---|
| `Icons.Rounded.SkipPrevious` | `BitChordIcons.TransportPrevious` |
| `Icons.Rounded.Pause` / `PlayArrow` | `BitChordIcons.TransportPause` / `TransportPlay` |
| `Icons.Rounded.SkipNext` | `BitChordIcons.TransportNext` |

- 新しい曲送りアイコンは横長なので、今のアイコンサイズ(24dp / 32dp)のままでも、旧アイコンより少し大きく見える。
- 実機で見て、曲戻し/曲送りが重く見える場合は 2dp 小さくする。

### C. 再生/停止ボタンの位置を中央へ
両方の実装で、曲戻しと再生/停止の間にも、曲送り側と同じ 8dp の隙間を入れる。

```
[曲戻し][8dp][再生/停止][8dp][曲送り]
```

- 曲戻しボタンを非表示にする設定(`miniPlayerPreviousButton`)のときは、この隙間も出さない。
- 縮んだ表示(inline、曲送りなし)のときは、曲戻しと再生の間だけに隙間を入れ、並びの見た目を揃える。
- アイコン自体が左右対称になる(旧 `SkipPrevious` の縦棒がなくなる)ので、見た目の重心の偏りも同時に解消する。

## 確認方法
1. `assembleStandardDebug` でビルドし、`adb install -r` でスマホに入れる。
2. 再生画面:曲戻し/曲送りの三角が先端でわずかに接する程度か、停止ボタンの線が細くなったかを確認する。
3. ボトムバーのミニプレーヤー:
   - 広がった状態と、スクロールして縮んだ状態の両方で、新アイコンになっているか。
   - 再生/停止ボタンが曲戻しと曲送りのちょうど中間にあるか。
4. 設定でクラシックなボトムバーに切り替え、旧式ミニプレーヤーでも同じく確認する。
5. 設定で「ミニプレーヤーの曲戻しボタン」をオフにして、隙間が残らないことを確認する。
