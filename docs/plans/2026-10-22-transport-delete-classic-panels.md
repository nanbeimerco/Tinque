# 曲送りの位置・削除後のアニメーション・通常版の歌詞とキュー — Implementation plan

## 要望
1. 曲戻し・曲送りボタンの位置を変える。目安は、下の列のアイコンを 3 つにしたときの両端のアイコンの中心。そこより、曲戻し・曲送りの三角の接合部がわずかに外側に来るようにする。通常版とベータ版の両方。
2. 曲を端末から削除したあと、画面がバタつくアニメーションが入る。
3. 通常版の再生画面で、歌詞を大きく表示するときとキューを開いたときの動きを、できるだけそろえる。開いた後の画面はベータ版と同じレイアウトにする。

---

## Ch1. 曲戻し・曲送りの位置

### 今の作り
- 曲戻し・再生/一時停止・曲送りの 3 つを、行の幅に均等な間隔で並べている。
- Vivo の幅(再生画面の中身の幅 約 301dp)では、曲戻しの中心は左端から約 56dp。

### 目安の位置
- 下の列を 3 つにしたとき、1 つの幅は (幅 − すき間 6dp) ÷ 3。端のアイコンの中心は、端から (幅 − 6dp) ÷ 6。Vivo では約 49dp。
- 曲戻し・曲送りのアイコンは、2 つの三角の接合部が、ほぼアイコンの中心にある。
- **接合部(= アイコンの中心)を、目安より 4dp 外側に置く**(決定 AG)。Vivo では端から約 45dp で、今より約 11dp 外側に広がる。
- 再生/一時停止ボタンは、今どおり真ん中。

### 作り
- 3 つのボタンを均等配置するのをやめて、上の計算で曲戻し・曲送りの中心の位置を決めて置く。
- 下の列に実際にいくつボタンを出しているかに関係なく、「3 つのとき」の位置を使う(位置が設定で動かないように)。
- **10 秒送り・戻しのボタンを出しているときは、今の均等配置のまま**(決定 AH)。ボタンが 5 つになり、外側に広げる余裕がないため。
- 通常版・ベータ版、キューを開いているときも同じ位置。

---

## Ch2. 曲を削除したあとのバタつき

### 原因(コードから特定)
- 削除が終わると、端末の曲をすべて読み直している。曲の一覧がまるごと新しくなる。
- フォルダタブでは、一覧が新しくなるとフォルダの木も作り直される。今のフォルダの画面は、「同じフォルダ」でも中身が変わっただけで **別の画面に移った** と扱われる。そのため、画面が横に滑る切り替えのアニメーションがその場で流れる。これがバタつき。
- 曲・アルバムのタブは、同じ画面なら切り替えのアニメーションが流れない作りになっている(見比べ済み)。

### 対応
- フォルダタブの画面切り替えも、**フォルダの場所(パス)が同じなら切り替えのアニメーションを流さない** ようにする(曲・アルバムのタブと同じ作り)。削除した曲の行だけが、一覧から抜ける動きになる。
- ライブラリ(プレイリスト・お気に入り)と検索から削除したときも、同じことが起きていないか実装時に確かめ、起きていれば同じ形で直す。

## Ch3. 通常版の歌詞とキューを、ベータ版と同じ動きに

### 今の通常版
| | 歌詞を大きく表示 | キューを開く |
|---|---|---|
| 開いた後の画面 | 歌詞のページ(上に出典・閉じるボタン・小さな再生ボタン、操作系はすべて消える) | 上の帯 + キュー + 操作系(詰めた配置) |
| 曲名の行 | アートと一緒に上へ移動 | アートと一緒に上へ移動 |
| 音量バー | 消える | 消える |
| ミニ歌詞 | 消える | 残る |

### 変更後の通常版(開いた後はベータ版と同じレイアウト)
| | 歌詞を大きく表示 | キューを開く |
|---|---|---|
| 開いた後の画面 | 上の帯 + 歌詞 + 操作系 | 上の帯 + キュー + 操作系 |
| アート | 今まで通り、上の帯へ縮みながら移動 | 同じ |
| 曲名の行 | その場でフェードアウトし、上の帯でフェードイン(ベータ版と同じ) | 同じ |
| 音量バー | 消える | 消える |
| 再生バー・再生ボタン・ミニ歌詞 | 音量バーが消えた分だけ下がる | 同じ |
| ミニ歌詞 | 消える(歌詞を大きく出しているので) | 残る |
| 再生ボタンのまわりのすき間 | 変えない(詰めない) | 変えない(今の「詰める」動きはやめる) |

- 歌詞は、ベータ版と同じく上の帯と操作系の間に流れる(今の行の強調、行を押して移動)。
- 「歌詞をアートの場所にだけ表示する」設定がオンのときは、今まで通り(アートの場所に歌詞を出す)。

### 出典表示とログは、歌詞の最後に置く
- 今の歌詞のページでは、上の帯に「歌詞の出典(〜による歌詞)」「保存しました」などの表示と、ログを開くボタンがある。
- 新しい表示では、これらを **歌詞の一覧の最後** に置く。最後までスクロールすると、再生バーのすぐ上に出る。
  - 出典の表示(「歌詞を表示しない」系の設定がオンなら出さない。今の設定にそのまま従う)
  - ログを開くボタン(「歌詞のログを表示」設定がオンのときだけ)。押すと、歌詞の場所にログが開き、閉じるボタンで歌詞に戻る。
- 歌詞の自動スクロールは今の行を追うので、ふだんは見えず、自分で最後までスクロールしたとき(または曲の終わり近く)に見える。
- 通常版・ベータ版の両方。

### 使われなくなる設定(決定 AI)
今の歌詞のページにだけあった **小さな再生ボタン** の設定(表示・大きさ・中央寄せ・曲戻しボタンの表示)は、新しい表示では使われない。操作系がそのまま残るため。

**推奨: これらの設定項目を設定画面から外す。**(値は残しておき、元の歌詞ページを戻すことになれば使えるようにする)。出典表示・ログの設定は、歌詞の最後の表示に効くので残す。

## 決めてほしいこと
| # | 論点 | 推奨 | 代替 |
|---|---|---|---|
| **AG** | 曲戻し・曲送りを目安より外側に出す量 | **4dp** | 2dp / 8dp |
| **AH** | 10 秒送り・戻しを出しているとき | **今の均等配置のまま** | 曲戻し・曲送りは同じ位置にし、10 秒ボタンをその外側に詰める |
| **AI** | 使われなくなる歌詞ページの小さな再生ボタンの設定 | **設定画面から外す**(値は残す) | 残す(何も起きない項目になる) |

## 確認方法(Vivo)
- 曲戻し・曲送りの中心が、下の列 3 つのときの端のアイコンの中心より少し外側にあること(通常版・ベータ版・キュー表示中)。10 秒ボタンを出しているときは今のまま。
- フォルダの中で曲を削除しても、画面が横に滑らず、削除した行だけが消えること。
- 歌詞を最後までスクロールすると、再生バーの上に出典の表示(とログのボタン)が出ること。ログを開いて閉じられること。
- 通常版で歌詞ボタン・キューボタンを押すと、アートは上の帯へ移動し、曲名の行はその場でフェードアウトして上の帯でフェードインすること。音量バーが消え、操作系がその分だけ下がること。歌詞ではミニ歌詞が消え、キューでは残ること。閉じると元に戻り、ぴくつかないこと。
- ビルドして `release_apk\<version>_<内容>\` に置く。
