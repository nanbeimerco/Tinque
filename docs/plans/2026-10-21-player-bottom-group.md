# 再生画面 下の操作列の作り直し — Implementation plan

## 何をするか(まとめ)
1. **下の操作列を「区切られたボタン群」に作り直す**(モックのパターン 2)。
2. **下の列のアイコンを、下の列専用の線のアイコンに差し替える**(ほかの画面は変えない)。
3. **キューを開いている間も、下の列を残す。**
4. **曲名の横の丸ボタンのアイコンを大きくする**(丸の大きさはそのまま)。

変えないもの: 曲名の行の丸ボタンの大きさと色、シークバー、再生ボタン、音量バー、ボタンの表示・並び順の設定、ほかの画面のアイコン。

## デザインの考え方
再生画面は「アートの上に白だけ」の独自の作りを守る。M3 Expressive からは、操作の分かりやすさ・手応え・動きの考え方だけを借りる。

---

## 1. 下の操作列を区切られたボタン群に

### 形と色
| | オフ | オン |
|---|---|---|
| 背景 | 白 18%(曲名の横の丸ボタンと同じ) | 白 40% |
| 形 | 角ばった形(角 8dp)。列の両端だけ外側を丸く | 丸(カプセル) |
| アイコン | 白 100% | 白 100% |

- ボタンは 3dp のすき間で区切り、列の幅いっぱいに均等に並べる。高さ 48dp。
- ボタンの数は設定で 1〜7 個に変わる。両端の丸めは、実際に並んだ最初と最後のボタンに付ける。1 個だけのときは全体をカプセルにする。
- プレイリスト・検索(別の画面へ移るだけ)には、オンの状態はない。

### 動き
| 場面 | 動き |
|---|---|
| 押したとき(全ボタン共通) | 押している間だけ 0.9 倍に縮み、離すと弾んで戻る |
| オン ↔ オフ | 形(角 ↔ 丸)は 0.6 秒、色は 0.35 秒。速く動き出してゆっくり止まる(emphasized)。はね返りなし |
| リピート | 押すたびに矢印が半回転して次の段階へ(オフ → 全曲 → 1曲 → オフ)。形が変わるのはオフとの行き来だけで、全曲 → 1曲は丸のまま |
| シャッフル・お気に入り・歌詞・キュー | オンになったときだけ、アイコンが一度弾む |

### 今の仕組みで残すもの
- シャッフルの連打防止(0.4 秒)
- 振動の種類、読み上げ用の説明文
- お気に入りが使えないときの無効表示
- 歌詞とキューの片方を開くと、もう片方が閉じる動き

---

## 2. 下の列専用のアイコン

モックで使った Tabler Icons(MIT ライセンス)の形を、下の列専用のアイコンとして `BitChordIcons` に追加する。コードに出典を書く。線の太さは 22dp 表示で合うように調整する。

| ボタン | 今 | 差し替え後 |
|---|---|---|
| シャッフル | 独自の細い線 | 交差する2本の矢印 |
| リピート | 独自の細い線 | 角の丸い輪と矢印 |
| 1曲リピート | 「1」の文字だけ | 輪の中に「1」 |
| 歌詞 | Material(塗りつぶし) | 吹き出し |
| お気に入り | 独自の細い線 | ハート(オンのときは塗りつぶし) |
| キュー | Material(塗りつぶし) | 3本線 |
| プレイリスト | Material(塗りつぶし) | 線と音符 |
| 検索 | 独自の細い線 | 虫めがね |

- 専用のアイコンなので、メニュー、選択ツールバー、タブバーなど、ほかの画面のアイコンは変わらない。
- お気に入りを星にする設定のときは、星も同じ線の形で用意する。

---

## 3. キューを開いている間も下の列を残す

- 今は、キューを開くと再生ボタン・音量バー・下の列がまとめて畳まれる。
- 変更後は、**再生ボタンと音量バーだけを畳み**、下の列はキューのすぐ下に残す。畳まれる間に、下の列が上へ滑って収まる(位置が飛ばない)。
- キューを開いたままシャッフルを押すと、キューの並びがその場で入れ替わる様子が見える(キューの行には、並びが変わると動く仕組みが入っている)。
- 下の列のキューボタンは、開いている間はオン。押すとキューが閉じる。歌詞ボタンを押すと歌詞に切り替わる。
- **歌詞を大きく開いたときは今のまま**(下の列も消す)。

---

## 4. 曲名の横の丸ボタンのアイコンを大きく

- 丸は 34dp のまま。中のアイコンを **19dp → 22dp** にする(太らせる処理はしない)。
- 対象は、曲名の横に並ぶボタンすべて(クイックアクションの各ボタンと ⋮)。

---

## 対象ファイル
| ファイル | 内容 |
|---|---|
| `ui/player/NowPlayingScreen.kt` | 下の列を新しいボタン群に差し替え(`BottomGlyph` を置き換え)。キューを開いたときの畳み方の変更。`CircleGlyph` のアイコンを 22dp に |
| `ui/icons/BitChordIcons.kt` | 下の列専用のアイコン 11 種(シャッフル、リピート、1曲リピート、歌詞、ハート、塗りハート、星、塗り星、キュー、プレイリスト、検索) |

## 決定事項
| # | 論点 | 決定 |
|---|---|---|
| V | オンの白の濃さ | 40% |
| W | 1曲リピートのアイコン | 輪の中に「1」 |
| X | 曲名の横のアイコン | 22dp に大きくするだけ(太らせない) |
| Y | キューを開いたときの下の列 | 残す(歌詞を大きく開いたときは今のまま消す) |
| Z | 下の列のアイコン | 下の列専用の線のアイコンに差し替え。ほかの画面は変えない |

## 今回は対象外(次の回以降)
- **アプリ全体のアイコンを線の形にそろえる**: 同じアイコンが場所によって別の意味で使われている(例: `QueueMusic` が「キューに追加」と「プレイリストの絵」、`PlaylistPlay` が「次に再生」と「プレイリスト」)。アイコンごとではなく意味ごとに置き換える必要がある。メニュー・選択ツールバー・タブバーをまとめて扱い、選択ツールバーの 3 つ(次に再生 / キューに追加 / プレイリストに追加)が見分けられるかをモックで確かめてから決める。
- **リピートの状態をキューに表示する**(キューの最後に「最初に戻る」印など)。
- **Chromecast のクイックアクションボタンの見た目をほかの丸ボタンにそろえる。**

## 確認方法
- ボタンの数を 1〜7 個に変えても、両端だけが丸く、すき間と幅がそろうこと。
- オンオフで、形が 0.6 秒で変わること。押している間だけ縮むこと。
- リピートを 3 回押して、オフ → 全曲 → 1曲 → オフと進み、矢印が毎回回ること。全曲 → 1曲で形が戻らないこと。
- シャッフルの連打で状態が乱れないこと。
- キューを開くと、再生ボタンと音量バーだけが畳まれ、下の列が位置を飛ばさずにキューの下に収まること。開いたままシャッフルを押すと、キューが並べ替わること。
- 歌詞を大きく開いたときは、今と同じく下の列が消えること。
- 曲名の横の丸ボタンで、丸の大きさが変わらずアイコンだけ大きくなっていること。
- 明るいアートワークと暗いアートワークの両方で、オンとオフが見分けられること。
- ほかの画面(メニュー、選択ツールバー、タブバー)のアイコンが変わっていないこと。
- ビルドして `release_apk\<version>_<内容>\` に置く。
