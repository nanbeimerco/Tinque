# ベータ版プレイヤーレイアウト — Implementation plan

## 方針
- 前回(`2026-10-21-search-menu-and-player-layout.md`)で入れた **再生画面の配分の変更** と、その後の **音量バー・再生ボタン・アートの変更** を、設定の「ベータ版プレイヤーレイアウト」トグルの中に移す。
- **トグルがオフ(既定)のときは、前回の変更より前の再生画面に戻す**(v2.4.1 の再生画面と同じ)。
- 前回の **不具合の修正はトグルに関係なく残す**:
  - 「最近再生」「よく再生」の 3点ボタン
  - 検索結果の長押し・3点ボタン
  - 検索から開いたアルバムの全画面カバーアート
- ベータ版には、さらに 2 つを足す:
  1. ミニ歌詞(再生バーの上の 1 行の歌詞)をなくし、空いた分で曲名の行・再生バー・アートの位置を整える。
  2. 下の列の歌詞ボタンで、今の歌詞画面ではなく、**操作系はそのまま、曲名の行だけが上に移り、空いた所に歌詞が出る** 表示にする。

---

## 1. トグル

- 設定の再生画面の項目に「ベータ版プレイヤーレイアウト」を追加する(既定はオフ)。説明: 「操作を画面の下にまとめ、アートを大きく表示します。歌詞は再生画面の中に表示します。」
- 切り替えは、再生画面を開いたままでもその場で反映する。

### オフ(既定)= 前回より前の再生画面
| 項目 | 内容 |
|---|---|
| 操作系のすき間 | 縦長の画面では、余った高さを再生ボタンの上下に配る(今まで通り) |
| アートと曲名の行 | ひとかたまりで、上の空きの中央 |
| アートの大きさ | 左右の余白 30dp |
| 音量バー | 「音量バーを隠す」設定に従う。**既定は表示に戻す** |
| ミニ歌詞 | 「ミニ歌詞を表示」設定に従う(今まで通り) |
| 歌詞ボタン | 今の歌詞画面 |

### オン = ベータ版
| 項目 | 内容 |
|---|---|
| 操作系 | 余った高さを配らず、画面の下にまとめる |
| 曲名の行 | 操作系の上にくっつける |
| アート | 曲名の行より上の空きの上下中央(全画面カバーアートのときは上端から)。左右の余白 20dp で一回り大きく |
| 音量バー | 表示しない(決定 AD) |
| 再生ボタン | 時間の表示と下の列のちょうど中間 |
| ミニ歌詞 | 表示しない |
| 歌詞ボタン | 下の「3. ベータ版の歌詞表示」 |

---

## 2. ミニ歌詞をなくした分の調整(ベータ版)
- ミニ歌詞の行(約 36dp)がなくなる。
- **曲名の行と再生バーの間** を、詰まりすぎず広すぎない量に決め直す。目安は、曲名の行の下端から再生バーまで 20dp 前後。
- 空いた残りの高さは、アートの上下に回る(アートは上の空きの中央に来るので、アートが少し下がり、上下の余白が少し増える)。
- 数字は実機(Vivo)の画面で確かめて決める。

---

## 3. ベータ版の歌詞表示

### 動き
1. 下の列の歌詞ボタンを押す。
2. **操作系(再生バー、再生ボタン、下の列)は動かない。**
3. **アートは縮んで、曲名の行と一緒に画面の上に移る**(決定 AE)。上の帯は、キューを開いたときと同じ「小さなアート + 曲名・アーティスト + 右の丸ボタン」。
4. 上の帯と再生バーの間の空いた所に、**歌詞が流れる**(今の歌詞画面と同じく、今の行が強調され、行を押すとその位置へ移動する)。
5. もう一度歌詞ボタンを押すか、戻る操作で元に戻る。

### 作り
- キューを開いたときの仕組み(アートが上の帯に縮み、操作系は残る)をそのまま使い、中身をキューの一覧ではなく歌詞にする。
- 歌詞の表示部分は、今の歌詞画面の歌詞の部品をそのまま使う(同期歌詞の強調、行を押して移動、自動スクロール)。
- 歌詞がない曲では、空いた所に「歌詞がありません」を出す(今の歌詞画面と同じ表示)。
- キューボタンを押すと、歌詞からキューに切り替わる(今と同じく片方だけ開く)。
- 今の歌詞画面にある、歌詞の出典表示・ログ表示・小さな再生ボタンは、ベータ版の歌詞表示には出さない(決定 AF)。

---

## 決めてほしいこと
| # | 論点 | 推奨 | 代替 |
|---|---|---|---|
| **AD** | ベータ版の音量バー | **表示しない**(「音量バーを隠す」設定より優先) | 「音量バーを隠す」設定に従う |
| **AE** | 歌詞を出すとき、アートはどうなるか | **曲名の行と一緒に上の帯に縮む**(キューと同じ見た目) | アートは消え、曲名の行だけが上に移る |
| **AF** | ベータ版の歌詞表示に出すもの | **歌詞だけ**(出典・ログ・小さな再生ボタンは出さない) | 出典の表示だけ、歌詞の上に小さく出す |

## 確認方法(Vivo で確認)
- トグルがオフのとき、再生画面が v2.4.1 と同じ見た目であること(音量バーあり、ミニ歌詞あり、アートと曲名がひとかたまり)。
- トグルがオンのとき、操作系が下にまとまり、ミニ歌詞と音量バーがなく、曲名の行と再生バーの間が自然であること。アートが一回り大きく、上の空きの中央にあること。
- ベータ版で歌詞ボタンを押すと、操作系は動かず、アートと曲名が上の帯に移って、空いた所に歌詞が流れること。行を押すと移動すること。もう一度押すか戻る操作で戻ること。キューとの切り替えができること。
- 再生画面を開いたままトグルを切り替えても崩れないこと。
- 不具合の修正(履歴の 3点、検索の長押し・3点、検索のアルバム)が、トグルに関係なく働くこと。
- ビルドして `release_apk\<version>_<内容>\` に置く。
