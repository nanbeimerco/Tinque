## 1. タブ切り替えをフェードだけにする

- 今：タブを切り替えると、新しいページが 8% 横から入りつつフェードイン（260ms、`MainActivity` のタブ到着アニメーション）。
- 変更：横の動きをやめ、**フェードだけ**にする。長さは 200ms 前後に縮める。
- 「動きを減らす」がオンのときは、今と同じく何もしない。

## 2. ポップアップのアニメーションを作り直す

### 2-1. 動画の解析結果（`Liquid Glass_sample/popup.mp4`、`popup_2.mp4`）

Apple Music の曲の行の「⋯」から開くメニューです（30fps、`popup_2` は同じ場面の拡大）。開き始めから止まるまで、**約 150ms** です。

| 時刻（開き始めを 0） | 見え方 |
|---|---|
| 0ms | 押した「⋯」ボタンの位置から、**縦に長い細いカプセル**が現れる。高さは最初から最終の 8〜9 割。中身（メニューの文字）は**最終の大きさのまま**、強くぼけて、カプセルの幅で切り取られている（中身は縮んでいない） |
| +35ms | カプセルが**左へ**広がる（右端は「⋯」の位置に固定）。上下も最終の高さまで伸びる。中身はまだぼけている |
| +70ms | 幅が最終に達し、**少し大きすぎる**（約 1.03〜1.05 倍）。中身のぼかしが取れ始め、上の「追加・お気に入り・共有」の列が見える |
| +100〜150ms | 大きすぎた分が戻って止まる。中身がくっきりする |

まとめると、

- **形**：ボタンから「縦→横」の順に広がる。縦はすぐ、横は少し遅れる（別々のバネ）。
- **固定点**：右端（ボタンの側）。メニューはボタンの上下にまたがり、ボタンの行のまわりに開く。
- **中身**：縮めずに「窓」で見せる。ぼかし → くっきり、透明 → 不透明。
- **最後**：少しだけ大きすぎてから戻る（弾み）。
- 閉じる動きは動画にないので、開く動きの逆再生（中身がぼけながら、横→縦の順に縮んでボタンに吸い込まれる）を提案する。

### 2-2. 進め方

1. **モックを作る**（`mocks/popup_motion.html`）：今の開き方と、動画を元にした新しい開き方を並べる。速さ（実時間・スロー）、バネの強さ、開く向き（下向き・上向き）を切り替えられるようにする。
2. 決まった動きを、アプリの Glass のメニュー（`GlassFloating.kt` の `GlassMenuController` が出すもの：曲の ⋮、プレイヤーの ⋮、並べ替えなど）に共通で入れる。
   - 幅・高さ・角の丸さを別々のバネで動かす（縦が先、横が後）。
   - 中身は Glass の窓で切り取って見せ、ぼかし（Android 12 以降は `RenderEffect`）と透明度をバネの進み具合に合わせる。
   - 開いている途中で閉じても、形が飛ばずにそのまま縮む。
   - 「動きを減らす」がオンなら、150ms のフェードと 0.95→1.0 の拡大だけ。
3. 確認：開閉のコマ落ちを `gfxinfo` で測る（ホームでのカクつき対策と同じ方法）。

## 3. 開いたポップアップの中をスクロールすると弾む

- 目的：ポップアップの中で指を動かしても、**後ろのページは動かない**ことを、ポップアップ自体の弾みで伝える。
- 中身がスクロールできる長さなら、端まで行ったところで弾む（Android の伸びる端の効果に近い）。
- 中身が短くてスクロールしないなら、指の動きに合わせてポップアップ全体が**少しだけ**（最大 8dp・1.5% ほど）伸びたりずれたりし、指を離すとバネで戻る。
- 後ろのページへのスクロールは、ポップアップが受け止めて渡さない（`nestedScroll` で消費する）。
- 2 のポップアップの作り直しと同じ部品に入れる。

## 4. アーティストページの切り替えを Glass のバーとピルにする

### 今の問題（スクリーンショットの「帯」）

- 「曲／アルバム／フォルダー」の切り替えと「ライブラリから削除」のチップが、**一覧の上に固定された帯**になっている。帯の下端で一覧がまっすぐ切れて見え、アプリの決まり（帯を作らない。ガラスは画面に浮かせる）から外れている。

### 直し方

- 下のタブバーと同じ作りにする：**Glass のバーの中を、選んだ項目のピル（`GlassSelectionPill`）が滑って移動する**。
- バーは帯ではなく、一覧の上に**浮かせる**（上のボタン類と同じく、後ろの一覧が透けて見える）。一覧はバーの下まで流れ込む。
- 「ライブラリに追加／削除」のチップは、バーの横の丸い Glass ボタン（アイコンだけ）にする。押すと、今と同じくトーストで知らせる。
- 曲・アルバム・フォルダーの切り替えは、ピルが移動する短いアニメーションと、中身のフェードだけにする（1 と同じ考え方）。
- 検索から開いたアーティストページにも同じ部品を使う（前回の残りの作業）。

## 5. プレイヤーで「ヒートの詳細」を開くと、プレイヤーの下に出る

- 原因：「ヒートの詳細」の画面（`HeatDetailsHost`）を、アプリの一番外側に 1 つだけ置いている。Glass の画面は「置いた場所の Glass の層」に出るため、プレイヤー（別の層の上にある）の**後ろ**に出ていた。
- 直し方：開くときに「どこから開いたか」（プレイヤーか、ほかの画面か）を一緒に渡す。プレイヤーから開いたときは、プレイヤーの Glass の層（`playerGlassMenus`）に出す。
- 確認：プレイヤーの ⋮ → ヒートの詳細、リストの ⋮ → ヒートの詳細、どちらも一番手前に出ること。

## 6. プレイヤーのお気に入り・⋮ ボタンの背景

- **決定（11/11）**：今のぼかしの背景（丸い Glass）を消し、**アイコンだけ**にする。
- お気に入りボタンは、押したら**中が塗りつぶされる**アイコンにする（未登録は線だけの星／ハート、登録済みは塗りつぶし）。切り替わるときに、M3 の小さな弾み（0.85→1.0 倍）を付ける。
- 押せる範囲（48dp）は今のまま残し、押したときの波紋だけ出す。

## 7. プレイリストを開く前と後でヒートの表示が違う

- 原因：計算の方法が違っていた。
  - 一覧の行・タイル：プレイリスト用の計算（`HeatStore.playlistLevel`：プレイリストから再生した記録、または熱い曲の上位 5 分の 1 の平均）。
  - 開いた後の見出し：アルバム用の計算（`HeatStore.groupLevel`：全曲で割るので、大きなプレイリストほど低く出る）。
- 直し方：開いた後の見出し（`DrillDownSongList` の通常の見出しと全画面アートの見出し）でも、プレイリストとお気に入りのときは**プレイリスト用の計算**を使う。開くときにプレイリストの ID（お気に入りなら専用の鍵）を渡す。
- アルバム・アーティスト・フォルダーは、今のまま（一覧と見出しで同じ計算）。

## 8. アイコンの初期値を「黒×白」にする

- **新しく入れた人**だけ、最初のアイコンを「黒×白」（`LauncherIcon.BLACK`、エイリアス `.LauncherBlack`）にする。更新した人は、今のアイコンのまま（初期値は新規インストールだけ、という決まりどおり）。
- やること：
  - マニフェストで、最初から有効なエイリアスを `.LauncherBlack` に変える（`.LauncherPink` は無効に）。
  - 設定の初期値：新規インストールの判定（既存の「初回の初期値」の仕組み）で `BLACK` を書く。更新した人で、保存された値がない場合は、`PINK`（通常）を書いてから使う。
  - 更新した人は、起動のたびに選んでいるエイリアスを有効にしているので、マニフェストの初期値を変えても、ホーム画面のアイコンは変わらない。

## 9. 「黒×白」だけ、中心補正 +1 をホーム画面にも効かせる

- ホーム画面のアイコンは、アプリに入れた絵を端末が表示するだけなので、位置を後から動かせない。そこで、**+1 ずらした「黒×白」を別の絵として入れ、エイリアスを 1 つ足す**（`.LauncherBlackShifted`、`ic_launcher_mono_shift1`）。
- 設定のアイコン画面で「黒×白」を選んでいるときだけ、「**マークを少し右へ（+1）**」のスイッチを出す。オンにすると、エイリアスを切り替えてホーム画面のアイコンも変わる。見本も同じだけずらす。
- 通知のアイコンは端末が 1 色で塗るので、今回は変えない（必要なら後で）。
- 今ある「中心補正（ベータ）+0〜+3」のチップは、見本だけに効くもので分かりにくいので、**このスイッチに置き換えて削除する**ことを提案する。

## 10. MusicBeatSP-main11_11 のセキュリティ対策を入れる

11_11 には git の履歴や説明の文書がなかったので、Tinque と中身を比べて、セキュリティのための変更を拾いました。Tinque にも当てはまるものだけを入れます。

| 対策 | 11_11 の場所 | Tinque の今 | 入れること |
|---|---|---|---|
| **ログイン情報を暗号化できないとき、平文で保存しない** | `auth/AuthStore.kt` | 暗号化に失敗すると、平文の保存先に切り替える | 平文には保存せず、その端末ではログインを使えないようにする。前のバージョンで平文に保存されたものは、暗号化した保存先へ移してから平文側を消す（移せないときも平文は消す） |
| **歌詞の拡張機能の入力チェック** | `feature/lyrics/domain/LyricsExtensionSecurity.kt` ほか | チェックなし | 拡張機能の ID を英数字と `._-` だけ・64 文字までに制限（フォルダーの外へ書き込まれるのを防ぐ）。リポジトリ・スクリプト・マニフェストの URL は https だけ。ダウンロードしたスクリプトは SHA-256 のチェックサムを照合。スクリプトが送るリクエストのヘッダーは 16KB まで。テスト（`LyricsExtensionSecurityTest`）も移す |
| **歌詞の通信を、アプリのログイン情報と分ける** | `data/Http.kt`（`lyricsClient`） | 歌詞もアプリ共通の通信を使う | 歌詞の取得と拡張機能のスクリプトには、Cookie やアカウントの情報を一切付けない専用の通信を使う。拡張機能が好きな URL にリクエストできても、ログイン情報が漏れない |
| **外から受け取った応答・ファイルの大きさに上限** | `Http.kt`、`Backup.kt`、`M3uPlaylistImporter.kt`、`M3uParser.kt`、`MusicoletBackupImporter.kt` | 上限なしで全部読み込む | 歌詞の応答に上限を付けて読む。バックアップの読み込みは 128MB まで（読みながら数える）。M3U は 16MB・5 万曲・1 行 8,192 文字まで。Musicolet のバックアップ（ZIP）は中のファイル数 1 万まで（空のファイルを大量に詰めた ZIP 対策） |
| **取り消しを握りつぶさない** | `MusicoletBackupImporter.kt` | すべての例外（`Throwable`）をまとめて捕まえている | 処理の取り消し（`CancellationException`）はそのまま投げ直し、通常の例外だけを捕まえる |
| **プレイリスト読み込み時の曲の照合** | `M3uPlaylistImporter.kt`、`MusicoletBackupImporter.kt` | ファイルの URI と ID を同時に比べる | まずファイルの URI で探し、見つからないときだけ ID で探す（別の曲に誤って結び付くのを防ぐ） |

入れないもの：

- 11_11 は自宅サーバー（Jellyfin・Navidrome）のために暗号化されていない通信（http）を許可しているが、**Tinque にはその機能がなく、今は http を禁止している**ので、そのままにする（許可しない）。
- WebDAV のログイン情報の扱いも、Tinque にはその機能がないので対象外。

## 実装メモ（11/11、v2.7.0）

- **2・3 ポップアップ**：モック（mocks/popup_motion.html）で決めた値をそのまま ui/components/PopupMotion.kt に入れた。中心の移動 1.5 倍、縦が先に伸びる度合い 0、閉じる速さ 1 倍、フェードのカーブは「なめらか」、ほかは初期値。開く位置は「ボタンをまたぐ」。ガラスの素材は Tinque のまま。開いた中を引っぱると最大 12dp だけ弾む（MenuStretch）。「アニメーションを減らす」がオンならフェードだけ。⋮ が開く方向へ 3dp 寄る動きは Modifier.glassMenuAnchor()（曲の行・プレイヤー・プレイリスト・フォルダーの ⋮ に付けた）。
- **4 アーティストページ**：GlassSegmentBar（Glass のバーと滑るピル）と、丸い Glass の「ライブラリに追加」ボタン（LibraryToggleGlassButton）。一覧の上に浮かせた。検索から開いたアーティストも、同じアーティストページを開くようにした。
- **5**：ヒートの詳細は、開いた場所の Glass の層に出す（プレイヤー用のホストを追加）。
- **6**：プレイヤーの曲名の行の右側のボタン（クイック操作・お気に入り・⋮）を、すべて背景なしのアイコンだけにした。状態が変わると 0.85→1 の弾み。
- **7**：プレイリスト／お気に入りの見出しのヒートを、タイルと同じ計算に（LocalDrillDownHeatKey）。
- **8・9**：新規インストールは「黒×白」。マニフェストの最初のエイリアスも .LauncherBlack。黒×白のときだけ「マークを少し右へ（+1）」スイッチ（.LauncherBlackShifted）。ベータの +0〜+3 は削除。
- **10**：AuthStore（平文に保存しない）、歌詞拡張の入力チェック・HTTPS のみ・SHA-256・サイズ上限、歌詞拡張専用の通信、バックアップ 128MB・M3U・Musicolet の上限、取り消しの投げ直し、URI 優先の照合。LyricsExtensionSecurityTest も移したが、既存の古いテスト（Genius・KuGou など）がコンパイルできないため、テストは実行できていない。
- **11**：ライブラリの「曲」でお気に入りに小さな星（ハート設定ならハート）。
